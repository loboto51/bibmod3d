Detachment order marker dials for 40k Apocalypse 2019 edition.

Contains two base plates with either an embossed marker design or a raised marker design depending on how you prefer to paint them. The central holes in the top and bottom parts are sized to push-fit 3mm x 2mm magnets. They come out to about the same size as the cardboard tokens.

They are quite thin so I recommend printing them in a darker colour else you might see the painted order markings through the bottom.

Update: Added v2 top and bottom parts that are a bit thicker to make handling easier
