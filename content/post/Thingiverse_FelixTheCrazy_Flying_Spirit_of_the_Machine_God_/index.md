Ever seen the Matrix movies? Me too. Great series. Doesn't this look like one of those thing from the machine city? No? Well I thought it did. No worries, it's still a cool model. 

This is meant to be part of a conversion for a Mars army dune crawler. Figured I should complete the whole original model first. The remix will be posted soon. 

---
Parts that need to print more than 1 will have _x#, where # is the number needed. 
Alignment and assembly is designed to be used with short pieces of 1.75mm filament.
The model should fit a standard X type flying base, but I have included a model for one if needed.
Parts have been oriented to print with the least visible layer lines or for the best strength. 

I've been having issues with Blender 2.8beta and scale. So let me know if any pieces are too big or too small. Likely they will be too big by 1000%.
