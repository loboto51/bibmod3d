A simple model of an Eldar jetbike that I created for FDM printing. 6mm to 8mm scale.

I have successfully printed this on Bambu A1 using both 0.12mm Fine @BBL and 0.20mm Standard @BBL setting.
Use "print by object" mode if you want to print multiple on a single plate. Something happens when printing by layers that causes the print to fail.

The model includes supports that come away very easily after printing.
