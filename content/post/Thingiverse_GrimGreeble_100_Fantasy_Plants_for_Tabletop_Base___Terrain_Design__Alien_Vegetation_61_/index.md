Description :

~~~
This is a massive collection of 100 new and unique fantasy / sci-fi tabletop plants, designed specifically for building detailed miniature bases and terrain pieces.

I had to explore quite a few worlds to put this set together. Now that it's finally done, this upload almost doubles the total number of plants in my collection. :-)

Over the years, I've designed and uploaded many different tabletop plants. Even though most weren't originally made with basing in mind, many people scale them down and use them that way. So I decided to create a dedicated set of freshly designed plants for miniature base building. And here it is!

**What's included:**
- 100 unique plants, organized as 20 different types with 5 variants each
- Every plant is available as an individual STL file (for printing just the ones you need)
- One additional combined file containing all 100 plants arranged in a single 17×17cm STL (if you want to print the whole set at once)
- Suitable for both FDM and SLA/resin printing

These models print without supports, just like most of my other plant designs.

Whether you're creating jungle bases, alien worlds, fantasy forests, or toxic wastelands, I hope that you'll have a lot of fun making these grow.

Happy printing!

**Btw. I'm always thinking about new plants and other terrain stuff. So if you have any suggestions, just let me know.**
