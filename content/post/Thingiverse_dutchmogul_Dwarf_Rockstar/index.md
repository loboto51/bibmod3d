~~~
This is my entry for the [Thingiverse Remix Challenge](http://www.thingiverse.com/challenges/RemixChallenge). I've been on a dwarf kick lately, so the first thing in the collection that caught my eye was [bendansie](http://www.thingiverse.com/bendansie/about)'s fantastic [Bearded Yell](http://www.thingiverse.com/thing:1376314) bust. Using Meshmixer to cut a chunk off the pedestal, I used MakerBot Desktop to arrange the head/beard into the body parts I used for my recent space dwarf model, [Ulfer Ironhead](http://www.thingiverse.com/thing:1929744). I'd always wanted to use [atartanian](http://www.thingiverse.com/atartanian/about)'s [Beefy Arms](http://www.thingiverse.com/thing:217849), so I figured this was a good a time as any. As I was posing them, I realized that this guy would look best rocking a sweet flying v, so I cobbled together a miniature guitar using bits from [Roy-Tore Hofstad](http://www.thingiverse.com/RoyToreHofstad/about)'s awesome [AMGP](http://www.thingiverse.com/thing:478982) using TinkerCAD (along with his studded bracer). I used a combination of Sculptris and TinkerCAD to make his rocky base, ran him through netfabb, and the rest is (rock) history.

I've included a "statue" version and a 28mm scale version (for all you fellow tabletoppers). You'll want to print this guy with support material (took us round 11 hours for the statue version).

We've set up a [Patreon page](https://www.patreon.com/illgottengames) for anyone who's interested in helping to fund us so we can keep making free and open sourced games like Pocket-Tactics, Wayfarer Tactics. and others, not to mention the growing catalog of gaming miniatures that you can use for whatever you want! (Psst... we take requests and commissions...)

Enjoy!
~~~
