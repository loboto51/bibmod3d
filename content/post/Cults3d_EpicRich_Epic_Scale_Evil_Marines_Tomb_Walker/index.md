Description :

~~~
Epic scale Evil Marines Tomb Walker. A simple remix of some bodies I found on Thingiverse so that they fit onto the legs for Miffles_Makes Tomb Walker. 
Also included some rescaled weapons for added variety.

The glaive/scythe arm is super thin so be careful. 

There are a lot of bits mixed into this so I will try credit all the sources. I am sure I will miss something, it has been a long time since I put these together.

Miffles_Makes for the Tomb walker parts
https://www.thingiverse.com/thing:2866258

Stahl_Hexer for the Doomglaive arm
https://www.thingiverse.com/thing:3905651

onebitpixel for the autocannons
https://www.thingiverse.com/thing:92623

AStupidFace for the super soldier sarcophagus
https://www.thingiverse.com/thing:3615679

outofstep for the chainsword
https://www.thingiverse.com/thing:493363

OldVersions for the heavy bolter
https://www.thingiverse.com/thing:182984

ThatEvilOne for the Powerplant and claws
https://www.thingiverse.com/thing:4292352

chris262 for the infantry walker body
https://www.thingiverse.com/thing:1683090

slavikk for the low poly skull
https://www.thingiverse.com/thing:906562
