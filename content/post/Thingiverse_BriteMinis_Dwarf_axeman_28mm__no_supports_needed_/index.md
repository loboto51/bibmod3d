Description :

~~~
A dwarf axeman inspired by a metal sculpture found on a <a href="https://goo.gl/maps/vqiBVZskGnk1bwjLA">beautiful tenement house in Łódź, Poland</a>. This is another fantasy creature based on architectural details found in Łódź. 
Suitable for 28mm tabletop games.
Created so that it does not need any supports and prints well on a cheap FDM 3d printer like the Ender 3.
There are variants with square and round bases.

**NOTE** The dwarf swordsman seen in the photo is <a href="https://www.patreon.com/posts/more-dwarves-31678805">available on my Patreon</a>.
