~~~
Some classic style infantry miniatures, hope you will have fun with them! They have the option to arms them to spear, sword or polearms too. The object contains chitubox files too, that I used to testprint them. 

The files also include some very seperated files, these are designed to use them in Udo's Customizer software, this will allow you, to customize your miniatures inside the software, and you can print out the fully assambled miniatures! These files are not work with the software yet, but if you want to format they will work, check out this Cults3D project, where you can download the the files for the software: https://cults3d.com/en/3d-model/game/medieval-infantry

Check out Udo's Patreon for more info how does that work: https://www.patreon.com/Udos3DWorld
