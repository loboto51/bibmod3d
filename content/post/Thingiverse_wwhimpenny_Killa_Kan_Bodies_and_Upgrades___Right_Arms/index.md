Description :

~~~
I was printing a few Killa Kans made from Thorlek's Killa Kan Bodies and Upgrades but discovered all of the arms were left arms. So I created a set of right arms. Thanks for the models Thorlek.

The files stl files for the right arms are the same scale as the original models, however I found that to match the correct scale of the GWs Killa Kans correctly you need to reduce them to 70% of the original when slicing. 
~~~
