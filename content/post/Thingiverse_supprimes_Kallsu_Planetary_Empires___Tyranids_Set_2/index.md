I have the old Planetary Empires set for using in 40K campaigns, however, the set only contains random landscapes and Imperial ruins. For our dynamic campaigns, I am making simple faction specific tiles for some of the major armies.

Here is the second set of Tyranid tiles. This set includes a birthing spore, a devourer spire, a bio-titan corpse, and two different bio-tunnels (not pictured). For our campaigns, as the Tyranids advance across the landscape we swap out normal tiles for Tyranid themed ones to represent the creep. These specialized tiles can also be used for Tyranid specific bonuses as opposed to GW's very basic use of Imperial structures, which made no sense thematically.  For instance, the birthing spores allow the controlling Tyranid player to add 200 additional points to their army list, while bio-tunnels allow the Tyranid player to jump from one tunnel tile to another in order to quickly gain access to other army tiles.  Get creative and use them however you think is fitting!
~~~
