04.03.2021 Edit. I have updated the model to be thicker. The original version was too thin after I test printed it.

This Lizardman, Kobold, or Skink is armed with his bow and his dagger. This is based on the original Skink Archer for the Warhammer Fantasy game but can be used for D&D as well. The Skinks can no longer be equipped with bows in Warhammer so this is a retro model.

You can find more warhammer models here https://darkgref.gumroad.com/

I have provided one stl with the entire model combined on a 25mm square base. I also have the components separated if you want to customize the posing for wargaming.
