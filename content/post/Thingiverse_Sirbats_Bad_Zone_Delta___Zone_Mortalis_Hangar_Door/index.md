~~~
Here's a hangar door I created to replicateone of the Bad Zone delta tile centres.

I'm building my tiles to be 20mm thick, with the zone mortalis floor tiles on top.

I'm using the gorgeous floor tiles from the talented Eberleg - go check out their work.

https://www.thingiverse.com/Eberleg/about

As such, this model is designed to sit on top of a 5mm base board with 15mm frame / egdes, then the tile on top (minus the centre four squares)

I've added a printable base / frame, which obviously you'll need four of if you don't want to cut any board / wood etc to make the tile frame yourself.

I've added 3.5mm holes into the corners in case anyone wants to add L.E.D lights into this item. If not the lights are included so simply print and glue into place.

Three sets of hangar doors, closed, and two stages of opening, I might see about adding a magnet system in a future build, but for now, simply pick the ones you like and glue into place, they should slide up easily from underneath and fiot into the frame.
~~~
