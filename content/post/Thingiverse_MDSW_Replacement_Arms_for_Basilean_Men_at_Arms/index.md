Description :

~~~
To replace the mis-scaled original Mantic Basilean Men-at-Arms arms.

I had 80 of the original MAA Basileans with the terribly oversized gorilla arms. I put these together to replace the sword and shield arm and they scale well and look pretty good. When I got these originally I was so disappointed that I shelved the entire army years ago without assembling anything. Now, I can get excited about this great army again!

I also created a spear version with longer shields. 

I wanted to use the original Mantic shields, but it was so much work removing the original arm, so I thought these shields would fit the Basileans nicely. Not recommended for FDM printing. I printed on mt Elegoo Mars with using only light supports (Auto) and was able to get quite a few sets on the build plate.

The shield is from cncmodels4you (3946113), but for some reason Thingiverse is not letting me add another remix source - will try to again to add later on. 
~~~
