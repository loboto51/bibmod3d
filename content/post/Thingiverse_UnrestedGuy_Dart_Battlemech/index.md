_General Updates:_
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

<h2>Based on Battletech's <a href="https://www.sarna.net/wiki/Dart_(BattleMech)"> Dart</a> Battlemech</h2>

Contains both .blend, .stl and baseless (B-).stl files for the Dart 3S, 6S, and 6T. Use .Blend files to customise the pose or the base file to make a custom variant.

I use a resin printer so I do not know how well it will work if a filament printer is used, but always make sure parts are supported. For resin printing, a lift height of 8mm above a platform allows for full drainage out of the hexbase.

You can request if you want me to make a specific miniature, or support at the second tier or higher on the<a href="https://www.patreon.com/UnrestedGuy"> Patreon</a> for a custom design.

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
~~~
