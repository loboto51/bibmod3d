# Hex Quest Addon - Roads

These are additional tiles for the [Hex Quest World Mapping System](https://www.thingiverse.com/thing:3728353) by [ClayRade](https://www.thingiverse.com/ClayRade/about).

## Content

The files are named after the following pattern

```
road-<kind>_<terrain>.stl
```

where `kind` denotes the form of the road (straigth, elbow, ...) and `terrain` denotes the type of surrounding terrain (e.g., plains, hills, swamp).

There are some tiles combining a road with another feature, such as a river. They are named in the following pattern

```
road-<road-kind>_<feature>-<feature-kind>_<terrain>.stl
```

where `road-kind` describes the form of the road, and `feature-kind` describes the additional feature. For instance, a loop of a river next to a straight road is named `road-straight_river-v_plain`.

You'll also find the Blender source file for your own customizations: **`roads.blend`**.
