I recently started to learn to use Zbrush and this opened a lot of options for me. I decided my first freerun project should be something for wargaming and thus I created this set of heads. They should be printed so that their height is 6-7 mm. My Prusa Slicer says it means the scale should be around 298 but it's best if you guys check it before you decide to print them in larger quantities.
