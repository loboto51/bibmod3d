These STL files are designed to equip my [Sculptris Dummies](https://www.thingiverse.com/thing:1972042). You won't be able to import these files into Sculptris, though once you get your character posed, you can align these parts in any model staging platform (MakerBot Deskto, Blender, Meshmixer, or 3D Builder are all good choices). All of these parts are also available in Andrew Stockton's awesome [Desktop Hero](https://www.kickstarter.com/projects/263291121/desktophero-free-3d-printable-character-maker) project as well (which is quite a bit easier than adjusting all the parts by hand). All of these weapons have been scaled to 28mm/Heroic scale, so they should be ready for any kind of miniature conversion if you want to print them separately.

If you make anything with these (including through Desktop Hero), let me know and post a link here in the comments section (and certainly post a remix when you have something printable). I'd love to see what you come up with!

You can find an expanding collection of compatible parts [here](https://www.thingiverse.com/dutchmogul/collections/desktop-hero-parts).

We've set up a [Patreon page](https://www.patreon.com/illgottengames) for anyone who's interested in helping to fund us so we can keep making free and open sourced games like Pocket-Tactics, Wayfarer Tactics. and others, not to mention the growing catalog of gaming miniatures that you can use for whatever you want! (Psst... we take requests and commissions...)

Enjoy!
~~~
