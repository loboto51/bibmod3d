Description :

~~~
The Light Armoured Tank is a recent adaptation of the Light Armoured Transport. Up-armoured and with a spacious turret, it is undergoing extensive testing with almost the entire Imperial weapons arsenal. If successful, it is expected to equip many armoured units across Imperial space as a replacement for the eponymous Leman Russ.

Inspiration extremely limited here, so I figured I'd give it all the weapons just to be sure. The turret looks off, but again, not much to work with. Use it as an alternate tank for either Epic Armageddon or Epic AU's Heresy supplement.

25/08/2018: Lowered the turret's height, shortened the side lascannons' length so they don't stick out so far. Altered the turret and middle so they are interchangeable with Epic Scale tank turrets.

27-10-2025: Found some updated files while going through the hard drive.
