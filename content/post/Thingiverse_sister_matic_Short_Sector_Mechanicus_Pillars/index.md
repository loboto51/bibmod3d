Description :

~~~
Imagine Sector Mechanicus pillars... but shorter! That's pretty much it. 

The main files provided have a notional height of 58.5mm, which means that they're the same height as Zone Mortalis pillars and walls. So this is nice if you want some cross-compatibility. 
It also means that pillars + platform + pillars = the height of a regular full-height 122mm Sec Mech pillar. So you can muck about with shorter levels that still tie into the big ones. 
They have pegs on top to locate into standard Sec Mech platforms. They are a slightly looser fit, intentionally, so be prepared to use glue rather than rely on push-fit. 

"F" models are a full pair of pillars. 
"L" and "R", you guessed it, are left and right pillars. I found it easier to support single pillars the way I wanted, and the split is barely noticeable when assembled. 
If you print separate pillars, you can of course combine any L with any R. 
All of them play nicely with mirroring, which does not affect the mating, so _theoretically_ there are 100 different combinations (since you wouldn't bother to mirror the ones with no greebles or the 0 greebles).

"reg_sup.zip" contains all separate pillars, supported exactly as I printed them for myself. 

If you want a slightly taller pillar, with a notional height of 61mm (i.e. half a regular pillar by itself), then look in the "tall.zip" folder. It's the same details, just adapted for a pillars with a taller lintel to make this possible. 
These might be useful to you if you're already using 61mm terrain pieces, e.g. [SevenUnited's Half Furnace 2](https://www.thingiverse.com/thing:6503327). 
I don't want this height and therefore have not printed them, so you'll have to support them yourself. 
~~~
