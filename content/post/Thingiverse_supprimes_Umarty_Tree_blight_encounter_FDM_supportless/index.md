~~~
I created this Blight tree for the campaign a long time ago, but it seems weird to post just the tree, so I made him some company

Set of figures consists of:
 - Twig blight 
 - Needle blight
 - Vine blight
- Tree blight

Small figures  (twig, needle and vine) were printed on a 0.2mm nozzle, but I know these guys are printed in large groups, so I tried to design them so that they would be okay on a 0.4mm nozzle too. 
Tree blight is huge monster, it has ~3 inch base so its made to be printed on 0,4 nozzle default.
As always, no supports needed. Have fun.
