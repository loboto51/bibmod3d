Dragon Emperor of Rhun on Palanquin in 10mm Scale

This model was inspired by the Dragon Emperor Kit from Games Workshop. This model was designed in 10mm scale to be used with the Warmaster Ruleset. This model was designed on a round base and a thinner version was designed to fit on a 20x40 warmaster base. A version of the Dragon Emperor on foot is also included on an individual base. Version 3 is the same square base without the sword being brandished off of the base by the carrier.

NOTE: These models have not been test printed.
