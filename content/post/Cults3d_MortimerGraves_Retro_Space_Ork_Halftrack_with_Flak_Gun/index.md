An addition for my wife's retro Speed Freekz army, this is a 28mm compatible interpretation of the old Epic Ork "Flakwagon" built from scratch in Tinkercad.

Included are two different options for the track guards (with / without side armour), three different rams, and a rear deck option if you want to run it as a trukk without the gun.

---
Update: 19 June 2022
Added an alternate rotary cannon style Flak gun. Reuses the same Gun Base as the original, along with 2x skinny pegs to attach front and back sections.
