I love the original 'Hex Quest' concept and will be using it in my upcoming D&D sessions. I plan to use it for the exploration of an unmapped continent (Xen'Drik in the Eberron setting). Each tile would represent half a day of travel on horseback and could lead to small adventures. When entering a tile, all surrounding tiles would be 'revealed' by rolling on a d100 table. That one is still in the making :)
You can find tiles for this system all over Thingiverse. Just scale the larger ones down to fist this system, or scale up this file to fit the larger tiles.
A great first collection of tiles can be found here: https://www.thingiverse.com/thing:3728353
I especially liked the farm tile as the small posts caused my printer to do some stringing between them, which makes it look like vines between wooden posts. No Idea if this was by design or not, but it looks great!
Other great sources: 
BigMrTong https://www.thingiverse.com/BigMrTong/collections/hex-war-games-tiles
DutchMogul https://www.thingiverse.com/thing:3239261



This remake of the grid file makes 3 adjustments:
- Fixes a slight error in the connecting tile spaces (these were bigger than the internal ones). 
- Makes the piece a bit thicker (robust) for tabletop purposes.
- Improves the connectors for increased stability
~~~
