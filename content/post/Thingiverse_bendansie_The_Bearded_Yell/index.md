I wasn't intending on doing a follow up piece to my previous sculpt, but got inspired by beardly goodness.

Character sculpt at relatively low, medium and high and highest poly counts.

File will need support material, but the top half of the model has been successfully printed on an UP printer, needing relatively low amount of supports. Should work great on a resin/SLA printer. Hoping to do a full test print soon, will see if a manually modelled support structure is needed for the hair. Was just too keen to make the file public and see what the community does with it. :)

Edit: Confirmed printable on FDM! Thanks ichibey!

Edit 2: Uploaded second option for all detail levels with a single shell, mostly to fix issues with the eyes. Thanks 3DWP! Zip file contains all detail levels.

Sculpted in Zbrush, preview renders in Blender, final check and stl file saved from Netfabb.

Approximate poly counts
Low = 137,000 tris
Med = 372,000 tris
High = 965,000 tris
Highest = 2,804,000 tris
