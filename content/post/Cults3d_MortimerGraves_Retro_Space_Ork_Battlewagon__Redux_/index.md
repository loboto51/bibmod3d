Description :

~~~
An updated and simplified version of my [Retro Space Ork Battlewagon](https://cults3d.com/en/3d-model/game/retro-space-ork-battlewagon) design for my wife's Rogue Trader and Second Edition Speed Freekz army.

This is a 28mm compatible interpretation of the old Epic Ork "Battlewagon" built from scratch in Tinkercad.

This version has the front cab, exhausts, and ram simplified into a single piece as the original was a bit fiddly to print and build. Wheels have been slightly improved, and some extra details (mostly rivets) added to all other parts. New parts are fully interchangeable with the older design.
~~~
