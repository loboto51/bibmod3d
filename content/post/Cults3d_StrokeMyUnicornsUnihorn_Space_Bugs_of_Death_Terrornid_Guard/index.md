This .STL library is meant as a space bug Terrornid Guard original model and needs to be printed on an SLA printer.

.STL library to create various SBoD Terrornid Guard bits, they fit on a 50mm base (not included, check out my base pack). Library features:

- Heads   3 types 4 poses
- Torso   2 types
- Shoulders   2 types 4 sub variants
- Tail Variants   2 types 6 poses
- Back Legs   1  types 6 poses
- Front Legs   1  types 6 poses 1 sub variant
- Talons   L&R 6 poses
- Crushing Claws   L&R 6 poses
- Shields   L&R 3 poses
- Swords   L&R 6 poses
- Whips   L&R 3 poses

Everything should be interchangeable between poses. Specific pose X legs and tails fits best together. Can be combined between poses but you might end up with wonky feet.
