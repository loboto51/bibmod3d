Description :

~~~
Digitally kitbashed together some human auxillary helmets for my army, thought it'd be good to share around. I've included 12 variants, but you could make a lot more using the parts available, so I've included a Blender file for people who want to make their own.

The heads are a little on the large side (I think they're in scale, guardsmen heads are just huge), I attached an example image of them which should give you an idea of size, depending on the body you end up using you might want to scale down a touch.

I've added a set of presupported heads, but I'm not super experienced with creating presupports so your mileage may vary. Printed perfectly for me but I have my settings pretty well dialed in and print with pretty conservative speeds.

These are based on Ziocru's Angry Spaceguards Hostile Environment Heads Set (https://cults3d.com/en/3d-model/game/angry-spaceguards-hostile-environment-heads-set), which is itself a remix from a few different creators;
