This is a collection of two different designs for Mek Gunz created by AgentSmith99 with remixes done by KEKSIMUS_MAXIMUS. The collection also includes weapons designed by AgentSmith99 which are intended to mount to both designs. A single grot mek designed by Tsipis is also included in the collection.

NOTE 1: All weapon options should be able to be mounted to the fixed gun or the towed gun designs.
NOTE 2: Recommend using a resin 3D printer, not required, but recommended.
NOTE 3: Size Reference https://www.dakkadakka.com/s/i/at/at2/2014/6/23/46409b009cd4ad6e8475f4b2eb651c10_56122.gif
WARNING: Always double check your printing dimentions before printing.
