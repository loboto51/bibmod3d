This .STL library is meant as a space bug cerebore original model and needs to be printed on an SLA printer.

.STL library to create various SBoD cerebore bits, they fit on a 170x105mm base (not included). Library features:

- Parts for 3 different poses.
- Semi Posable limbs
- Already sliced and hollowed parts
- Optional tentacle variations

All limbs should be interchangeable between poses. Body parts like carapace and heads are not.
