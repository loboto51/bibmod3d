Description :

~~~
This is a door & frame set for any tabletop sci-fi games out there. There's five different looking inserts and broken ones as well.

I had made these door inserts for my Dragon's Rest HVAC Tunnel Kit door set, so I decided to make a version of the door frame that could be used in any tabletop set, including original Spacehulk tiles. Also great for Zombicide: Invader and Dark Side. The door frame is scaled so that in 100% scale a 25mm base can fit between the door opening. And if you need a 32mm base to fit I suggest to scale the door to 135%. And so on. (I scaled them to 80% to fit my 20mm base scale.)

You can find more of my stuff on my MyMiniFactory Page:
https://www.myminifactory.com/users/Lupus78
~~~
