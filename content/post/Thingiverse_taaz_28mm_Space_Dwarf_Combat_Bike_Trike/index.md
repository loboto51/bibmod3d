This is a 28mm scale Combat Bike I whipped up to try to inspire myself into one day building a full 28mm scale Squats army. I haven't printed anything yet so if you do let me know how it turns out!

Update v1.2 I have made some changes to better fit these incredible models by MrOrangeJumper :https://www.thingiverse.com/thing:3706356

This includes lengthening the handlebar grips and redesigning the foot rests, I hope these fit them a bit better. I left the original body and handlebars as they could still fit normal sized humanoid legs. 

Update v1.3 I corrected and issue with the rear wheel peg being too long for the bike, so there is now a bike and trike rear wheel file.

Update 1.31 the awesome MrOrangeThing has uploaded some bolters that work with this design at https://www.thingiverse.com/thing:3737197!
~~~
