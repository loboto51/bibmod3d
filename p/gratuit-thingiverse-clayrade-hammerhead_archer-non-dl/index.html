This is 28mm scale miniature is ideal for tabletop role playing games such as D&D or Pathfinder. It is scaled to be printed as a -Large- miniature, which would fit on a 50.8mm diameter base. These sharks are big! If you attempt to print these as a medium sized creature, scale down to 50% (And take a picture, I'd love to see it!)

Feel free to glue a bit of string or fishing line or thin styrene in as a bow string :D

Included is a pre-supported Chitubox file that includes the Bullshark and Hammerhead for resin printing that has been tested and adjusted. Test printing was done on an Elegoo Mars in Elegoo Standard Gray at 7.7s / layer. I suggest running it through the Photon File Validator before printing!
